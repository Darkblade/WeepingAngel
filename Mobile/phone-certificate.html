Phone microphone setup

The microphone needs a trusted HTTPS connection. Archive playback works over your normal LAN address.

Checking the local certificate…

Download public CA certificate

Restart the phone interface in Windows: Settings → Connection → Stop phone interface, then Start phone interface. This enables the HTTPS address.

  1. Prepare and download this PC’s public certificate. Its private key stays on the PC.
  2. Compare the SHA-256 fingerprint with the certificate shown by Secure phone setup in Windows.
  3. On Android: Settings → Security → More security settings → Install from device storage → CA certificate. Select the downloaded certificate.
  4. Open Weeping Angel using its HTTPS address and pair this browser there. HTTP and HTTPS pairing are separate.

Only install the certificate for your own Weeping Angel PC. If the PC’s LAN address changes, restart the phone interface to update its server certificate.
